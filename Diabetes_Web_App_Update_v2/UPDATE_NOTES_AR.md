# تحديث التوعية الصحية وWhatsApp

## ما الذي أُضيف؟

1. **دليل قياس داخل نموذج التقييم**
   - اسم الجهاز المناسب لكل قياس.
   - خطوات مختصرة لقياس الضغط والسكر والوزن والطول بصورة أوضح.
   - تنبيه إلى أن قراءة السكر تحتاج معرفة هل القياس صائم أم عشوائي، وأن النتيجة توعوية وليست تشخيصًا.

2. **تحليل منفصل للمرأة الحامل**
   - توضيح أن نموذج الخطورة العام لا يشخّص سكري الحمل.
   - بطاقة لفحص سكري الحمل ومتابعة مواعيد الحمل.
   - بطاقة لضغط الدم أثناء الحمل وعلامات تستدعي رعاية عاجلة.
   - بطاقة للنشاط والغذاء أثناء الحمل.
   - بطاقة خاصة بالصيام في رمضان أثناء الحمل وضرورة الرجوع إلى فريق متابعة الحمل.

3. **إشعارات WhatsApp والنصائح الموسمية**
   - إرسال إشعار نتيجة التقييم مباشرةً عند وجود موافقة المستخدم ورقم هاتف صالح.
   - إظهار حالة الإشعار في صفحة النتيجة: وضع تجريبي، مُرسل، قيد الانتظار، أو فشل.
   - إظهار حالة WhatsApp وفترة رمضان في لوحة المستخدم.
   - إضافة مسار آمن لتجهيز وإرسال نصائح رمضان اليومية بواسطة مجدول خارجي.

## متغيرات Render المطلوبة

التطبيق يعمل بأمان أولًا في الوضع التجريبي:

```text
WHATSAPP_DRY_RUN=true
```

للإرسال الحقيقي بعد إعداد WhatsApp Cloud API واعتماد القوالب لدى Meta، أضيفي في Render:

```text
WHATSAPP_ACCESS_TOKEN=...
WHATSAPP_PHONE_NUMBER_ID=...
WHATSAPP_GRAPH_API_VERSION=v23.0
WHATSAPP_ASSESSMENT_TEMPLATE_NAME=diabetes_assessment_result
WHATSAPP_RAMADAN_TEMPLATE_NAME=ramadan_awareness
WHATSAPP_TEMPLATE_LANGUAGE=en
WHATSAPP_DRY_RUN=false
```

يجب أن تكون أسماء القوالب واللغة مطابقة تمامًا للقوالب المعتمدة في حساب Meta.

## تفعيل فترة رمضان

أضيفي هذه القيم في Render بصيغة `YYYY-MM-DD` وحدّثيها كل سنة:

```text
RAMADAN_START_DATE=2030-01-05
RAMADAN_END_DATE=2030-02-03
RAMADAN_PERIOD_NAME=Ramadan 2030
```

التواريخ السابقة مثال فقط وليست تواريخ رسمية. استخدمي التواريخ المعتمدة للسنة المطلوبة.

## تشغيل النصائح اليومية

أنشئي مجدولًا خارجيًا يرسل طلب `POST` مرة يوميًا إلى:

```text
https://YOUR-RENDER-DOMAIN/tasks/daily-notifications
```

مع الترويسة:

```text
X-Cron-Secret: قيمة CRON_SECRET الموجودة في Render
```

لا تضعي `CRON_SECRET` في GitHub أو داخل الواجهة. أثناء الاختبار اتركي `WHATSAPP_DRY_RUN=true` حتى لا تُرسل رسائل حقيقية.

## ملاحظات مهمة

- رسائل الحمل والتقييم للتوعية وليست تشخيصًا طبيًا.
- السؤال عن الحمل يظهر للأنثى فقط وفق منطق الواجهة الموجود.
- الإرسال لا يتم دون موافقة WhatsApp ورقم هاتف محفوظ للمستخدم.
- فشل WhatsApp لا يمنع حفظ نتيجة التقييم.
